# 游戏行业专项体检（dsh-industry-game）

**什么时候用**：游戏项目上线、版号申报、防沉迷与未成年人保护检查前的自查。
用户会说：「防沉迷要接成什么样」「实名认证漏了没有」「抽卡概率公示了吗」「版号展示在哪」「适龄提示要不要放」。

## 怎么用

```bash
<cli 路径> --root <项目目录>       # 检查一个项目
<cli 路径> --demo                  # 用内置样本看检出效果
<cli 路径> --list-rules            # 列出判据与出处
<cli 路径> --html report.html      # 出 HTML 报告（留档）
```

## 它查什么（5 条，全部 files-lack 型：有玩法特征但缺合规说明才报）

| 规则 | 触发特征（when） | 查什么 | 级别 |
|---|---|---|---|
| `GAME-ADDICTION` | 游戏/玩家/关卡/副本 | 无防沉迷或未成年人时段限制说明 | high |
| `GAME-REALNAME` | 游戏/登录/账号 | 无实名认证痕迹 | high |
| `GAME-LICENSE` | 游戏/玩家 | 无版号/出版审批信息 | high |
| `GAME-AGE-RATING` | 游戏/玩家 | 无适龄提示 | medium |
| `GAME-DRAW-PROB` | 抽卡/开箱/十连 | 无概率公示 | medium |

## 怎么读结果

- 出处：国家新闻出版署防沉迷通知（2021）、《网络安全法》第 24 条、《网络出版服务管理规定》、文化部规范网络游戏运营通知（2016）
- files-lack 是「整组都没有」才报一次——命中说明对应制度/页面整体缺失，补齐即可消除
- 5 条里部分因 `when` 不适用未运行时，报告会列出不适用清单——不适用 ≠ 没问题
